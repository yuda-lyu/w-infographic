Methods

(async) WInfographic(inp, opt) → {Promise}

Description:

  • 產製資訊圖 PNG

Source:
  • WInfographic.mjs, line 85
Example
import fs from 'fs'
import WInfographic from 'w-infographic'

let inp = {
    center: { title: '產品開發' },
    items: [
        { label: '需求', icon: 'mdi:clipboard-text', notes: ['訪談', '規格'] },
        { label: '設計', icon: 'mdi:pencil-ruler', notes: ['架構', '介面'] },
        { label: '實作', icon: 'mdi:code-tags', notes: ['開發', '審查'] },
        { label: '測試', icon: 'mdi:test-tube', notes: ['單元', '整合'] },
    ],
}

let buf = await WInfographic(inp, { type: 'circles', startAngle: -45 })
fs.writeFileSync('circles.png', buf)
// => 產出 circles.png
Parameters:
Name Type Description
inp Object

輸入正規化繪圖數據物件,格式依 opt.type:circles、hexagon 為 { center: { title }, items: [{ label, icon?, cls?, notes? }] }(hexagon 之項目另可給 side);hierarchy 為 { tree: { title, subtitle?, icon?, children: [{ title, desc?, items?, icon?, cls?, children? }] } }
opt Object

輸入設定物件

Properties
Name Type Attributes Default Description
type String

輸入圖種字串,必給,可選 'circles'(圓形放射圖)、'hexagon'(六邊形資訊圖)、'hierarchy'(層級樹)
startAngle Number | String <optional>
 -90

輸入 circles 之首個外圓角度數字或數字字串(度,-90 為正上方,順時針遞增),非有效數字(含 Infinity)或絕對值超過 360000 視為未給,預設 -90
mode String <optional>
 'p1'

輸入 hierarchy 之產線字串,可選 'p1'(純 HTML/CSS,不需網路)或 'p2'(d3-org-chart,自動 fit,需網路載 CDN),預設 'p1'
boxStyle String <optional>
 'band'

輸入 hierarchy p1 之節點版式字串,可選 'band'(色帶標題盒)或 'card'(卡片盒,不顯示節點之 items),預設 'band'
nodeWidth Number | String <optional>
 196

輸入 hierarchy p2 之子節點盒寬正整數或其字串(px),非正整數視為未給,預設 196
width Number | String <optional>
 1300

輸入 hierarchy p2 之畫布寬正整數或其字串(px),非正整數視為未給,預設 1300
height Number | String <optional>
 640

輸入 hierarchy p2 之畫布高正整數或其字串(px),非正整數視為未給,預設 640
compact Boolean <optional>
 false

輸入 hierarchy p2 是否緊湊佈局布林值,預設 false
Returns:

回傳 Promise,resolve 回傳 PNG 圖之 Buffer,reject 回傳錯誤訊息(inp 或 opt.type 不合、hexagon 單側超過 5 項、p2 無法連線載入繪圖庫時)
